Why we built it

Reviews are where good intentions run out of time.

Everyone agrees code review matters. Then it’s Thursday afternoon, there are eleven pull requests waiting, and the person who knows that part of the code is on holiday.

The bugs that slip through aren’t exotic. A loop that runs one step too far. A check that’s missing on one path. A library with a known hole in it.

Revylx is the colleague who has time to look at every change, every time. It doesn’t replace your reviewers. It gives them a head start, so their attention goes where it’s needed most.

How it fits into your day

It works where your team already works.

  1. Connect your GitHubAdd Revylx to the repositories you choose. There’s nothing to install on anyone’s laptop.
  2. Open a pull request as usualRevylx reviews the change and leaves comments on the exact lines that need attention, each with a severity, so you know what matters first.
  3. Talk to it in the pull requestAsk a question about the change, ask for a deeper look, or ask for a summary for whoever reviews next.
  4. Accept the fix, or don’tYour callAsk Revylx to make the fix and it commits it to the branch. If a fix looks risky, it opens a separate draft for you instead. Changed your mind? It can undo its own commit.

What it looks for

The things that bite you after you ship.

Bugs like off-by-one loops, missing checks and broken edge cases. Security problems in your own code. Libraries with known holes, and whether your code actually calls the risky part, so you’re not chasing warnings that don’t matter.

It also learns how your team writes code, so its suggestions sound like your codebase rather than a textbook. It reads TypeScript, JavaScript, Python, Go, Rust, Java and more.

Working today

  • Automatic review on every GitHub pull request
  • Line-by-line comments with severity and a suggested fix
  • Fixes committed on request, with a one-step undo
  • Questions, summaries and deeper reviews inside the pull request
  • Checks for vulnerable dependencies your code really uses

Still in progress
